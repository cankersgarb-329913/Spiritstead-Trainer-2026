## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Spiritstead**. This trainer provides optional quality-of-life enhancements for Spiritstead's village management, resource, building, progression, and spirit systems. It is designed for the single-player Windows version and can simplify construction, resource gathering, villager management, and exploration.

**Target Audience:** Players who want to experiment with village layouts, quickly test buildings and decorations, collect spirits, explore the game's biomes, or reduce resource and progression requirements during a single-player playthrough.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## ⚡ Features (v1.0)

### 🎯 Gameplay

- **Unlimited Resources** — Prevents selected village resources from decreasing while building, upgrading, decorating, or managing production.
- **Instant Construction** — Completes selected buildings, upgrades, and decorative projects immediately.
- **Freeze Villager Needs** — Keeps villager needs stable while you arrange jobs, improve services, and expand the settlement.
- **Maximum Happiness** — Maintains high villager happiness for easier management of cafes, markets, bonfires, and other happiness-boosting buildings.
- **God Power Cooldown** — Resets or removes cooldowns for available god powers, including weather-related abilities.

### 📌 Building

- **Unlock Buildings and Decorations** — Makes available selected buildings, decorations, upgrades, and settlement options without requiring normal progression.

### 📌 Progression

- **Instant Spirit Discovery** — Simplifies the discovery and collection of helpful spirits encountered through interactions with the world.

### 🌍 World

- **Fast Expansion** — Reduces or removes progression requirements for opening new territories and exploring additional biomes.

### ⚔️ Combat

- **No Combat Modifications** — Spiritstead is a village-building game without a conventional combat system, so combat-related trainer functions are not applicable.

## 📖 Detailed Feature Guide

### Movement & Exploration

Spiritstead focuses on navigating and managing a village rather than direct character combat. Use the normal game controls to pan across the settlement, inspect buildings, select villagers, and move between accessible areas. Activate trainer options only after the game world has finished loading.

### Tools & Inventory

Use the resource option while gathering materials, constructing buildings, placing decorations, or purchasing upgrades. Disable the option before changing areas or closing the game if the trainer version does not support persistent resource values.

### World & Environment

Explore the available territories and biomes to find resources, complete quests, meet villagers, and discover spirits. Fast expansion and unlock options can shorten normal progression, while spirit and god-power functions help you experiment with the game's magical support systems.

### Combat & Weapons

Spiritstead does not use a conventional combat system. Its core gameplay centers on village construction, resource management, villager needs, happiness, exploration, spirit discovery, quests, and progression through different regions.
